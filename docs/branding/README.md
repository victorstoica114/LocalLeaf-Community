# LocalLeaf Community branding

The current LocalLeaf identity was created for this community-maintained continuation in August 2026. Two overlapping documents represent local and remote copies of a project; the leaf between them keeps the mark tied to the LocalLeaf name.

This is not the original LocalLeaf logo and it is not an Overleaf mark. The design deliberately uses a different symbol, structure, and wordmark while keeping the familiar green language of LaTeX tools.

## Files

- `localleaf-community-wordmark.png` is the horizontal logo used in the README and on the website.
- `localleaf-community-icon-source.png` is the full-size transparent icon master.
- `localleaf-community-icon-512.png` is the web and social-preview icon.
- `localleaf-community-icon-128.png` is the VS Code extension icon.
- `exec-*.png` files preserve the selected raw image-generation outputs before cropping and transparency cleanup.
- `../../images/icon.svg` is a simplified monochrome companion made specifically for the VS Code Activity Bar.

The bitmap concepts were produced with OpenAI's built-in image-generation workflow, then selected, cropped, cleaned, and exported locally for this repository. The production files are included under the repository's MIT license.
